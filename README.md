# Carmel Cumbuco Resort - Digital Hub

Um hub digital minimalista e elegante para o Carmel Cumbuco Resort, apresentando informações sobre o resort com suporte para múltiplos idiomas (Português e Inglês).

## Características

- Design responsivo e minimalista
- Suporte para Português e Inglês
- Animações suaves e elegantes
- Integração com TripAdvisor e Booking.com
- Otimizado para dispositivos móveis
- Compatível com cartões NFC/RFID

## Tecnologias

- React 18
- Tailwind CSS
- Chart.js
- Babel (para JSX no navegador)

## Como usar

Abra o arquivo `index.html` em um navegador moderno. O site funciona completamente offline após o carregamento inicial.
